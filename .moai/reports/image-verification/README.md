`.moai/reports/`는 gitignore 대상이 아니므로 여기 남긴 파일은 커밋되면 저장소에 영구히 남는다.

| 파일 | 삭제 사유 |

| `d4-dense-1568.jpeg` / `d4-dense-1024.jpeg` | 기기 일련번호·IMEI가 화면에 찍혀 있다 |

**재검증이 필요하면 같은 절차로 다시 찍어야 한다**는 점을 여기 명시한다.

## 양성 대조 재현 절차 (AC-IMAGE-018)

대조 대상이 사라지면 대조는 죽는다. 왜곡 사본 생성은 다음과 같다:

```bash
cp <capture>.jpeg distorted.jpeg
node -e 'const fs=require("fs");
  const g=JSON.parse(fs.readFileSync("<capture>.jpeg.geometry.json","utf8"));
  const d={...g, deviceWidth:g.width, deviceHeight:g.height, scale:1};
  fs.writeFileSync("distorted.jpeg.geometry.json", JSON.stringify(d,null,2));'
```

`deviceWidth`/`deviceHeight`를 이미지 크기와 같게 맞추는 이유: `geometry.ts`가 가로·세로 배율이
1% 넘게 어긋나면 사이드카를 거부하므로, `scale`만 1.0으로 바꾸면 왜곡 사본 자체가 읽히지 않는다.
이 형태는 **호출자가 배율을 잊고 이미지 좌표를 그대로 넘기는 실수**를 정확히 재현한다.
